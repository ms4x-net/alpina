# Alpina Firmware Preservation

Alpina engine and transmission control unit files are rare, often hoarded, and replacement units cost far more than their BMW counterparts. This repository preserves verified Alpina firmware so cars can be repaired and kept original.

📖 Background on every model, part numbers and control units: **[Alpina Firmware Preservation on the MS4X Wiki](https://www.ms4x.net/index.php?title=Alpina_Firmware_Preservation)**

## File naming

`<Manufacturer>_<Unit>_<Software>_<Chassis>_<Engine>_<Displacement>_Alpina_<Model>_<Alpina #>_<VIN with last 4 characters as xxxx>_<Full|Bootmode|BDM>.bin`

Example: `Siemens_MS42_0110C6_E46_E4.4_3.3L_Alpina_B3_1356696_WAPB333L09ME4xxxx_Full.bin`

Folder structure: `<Chassis>/<Model>/`

## Verify downloads

```
sha1sum -c SHA1SUMS
```
